How uploads work

Each file is split into ~95 MB parts and streamed to R2 storage via multipart upload (max 10,000 parts → up to ~950 GB technically; capped here at 250 GB). If a part fails it is retried automatically. Your identity, device, IP and location are logged with every upload for safety.

Folders

Files live inside folders. A folder’s permission (Everyone / Staff Only) and each upload’s permission together decide who sees it. Create folders with + Folder.
